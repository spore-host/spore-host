The spore.host web app is being rebuilt

It isn't available right now. You can do everything today with the spore.host command-line tools. They run on your computer and work in your own AWS account.

The tools

  • spawn: launch and manage machines.
  • truffle: find machine types, availability and prices.
  • lagotto: wait for scarce capacity.

Install them

macOS or Linux (Homebrew)

brew install spore-host/tap/spawn
brew install spore-host/tap/truffle
brew install spore-host/tap/lagotto

Windows (Scoop)

scoop bucket add spore-host https://github.com/spore-host/scoop-bucket
scoop install spawn truffle lagotto

Debian, Ubuntu, RHEL or Fedora

Each tool has .deb and .rpm packages on its releases page: spawn, truffle, lagotto. The installation guide has the commands, and how to verify a download.
